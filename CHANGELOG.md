# Что изменено относительно исходников

- Вместо импорта hyprland.nix используется bspwm.nix; сохранён запасной Sway.
- Из журнала прошлого чата восстановлены desktop.py, Nix-модуль, темы, маски углов
  и последующие исправления. Рабочий результат не переписывался с нуля.
- В систему добавлены X11-сеанс Home Manager, PAM для i3lock, Blueman и шрифт Symbols Nerd Font.
- Профиль bspwm запускается только в его сессии, а не из общего sessionCommands.
- Убрана глобальная Wayland-переменная NIXOS_OZONE_WL; она осталась только в Sway.
- Убран больше не нужный Hyprland Cachix из configuration.nix. Неизменённый lock сохранён.
- Добавлена общая Matugen-палитра для X11; остальные пользовательские шаблоны сохранены.
- Kitty: удалён конфликтующий include current-theme.conf, добавлен same-user socket для live reload.
- Fastfetch: при отсутствии wallpapers/.face используется встроенный логотип NixOS.
- В Noctalia отключены плагины Wallhaven и Prism; само приложение Prism не удалялось.
- Обои: восстановление файлов тем при ошибках и таймаутах Matugen/feh.
- Flameshot не перезапускается на смене обоев, чтобы не потерять редактор.
- Добавлены инструкции установки/отката, preflight, тесты, журналы и X11-предпросмотры.

Реальные аппаратные параметры, диски, приложения и прочие пользовательские службы
не заменены «универсальным конфигом». Сверяй diff PR и предыдущую версию в истории Git перед установкой.

## Переработка оформления после визуальной проверки

- Полностью удалены шрифтовые торцы капсул Polybar и отдельные заливки модулей.
- Настоящие скругления 18–20 px, мягкие тени, единые отступы и спокойное выделение.
- Фотографические RGBA-превью с гладкими углами вместо цветных тестовых блоков.
- Нативные scale/fade-анимации Picom 13 для окон, меню и уведомлений.
- Настройки compositorBackend/reduceMotion; совместимый kernel blur для xrender.
- Полная перерисовка против остаточных теней; без экспериментального geometry stretch.
- Обновлены тесты, X11-снимки и запись действительных анимаций.
