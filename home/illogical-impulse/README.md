# illogical-impulse для Hyprland

В Hyprland запускается ii, а Sway использует Noctalia. Код оболочки и зависимости закреплены в `pkgs/illogical-impulse`; цвета генерируются matugen из обоев. Личные правила и анимации Hyprland сохранены, дополнены layer rules для ii.

`config/config.json` и `config/hypr-overrides/` подключены живыми симлинками. Изменения через GUI, избранные и пользовательские станции радио записываются в рабочее дерево репозитория. Для отдельного ПК можно задать `my.illogicalImpulseConfigDir`; в нём нужны `config.json` и каталог `hypr-overrides` с `main.lua`. Перед коммитом проверяйте изменения: конфигурация может содержать личные данные и ключи.

## Радио и уведомления

World Radio открывается сочетанием `Super+Shift+Z`: статистика и страны, жанры, поиск, избранное, свои потоки и управление mpv. Каталог — radio-browser.info; работает только при доступе к сети. Это самостоятельный интерфейс по мотивам плагина Noctalia, а не побайтовый перенос; полная синхронизация очереди MPRIS и метаданных/обложек не реализована. Плагин Wallhaven удалён, локальный выбор обоев остаётся.

В Hyprland используются всплывающие уведомления и история ii. Перед запуском ii скрипт завершает только принадлежащий текущему пользователю `dunst` или `mako`, если тот владеет D-Bus именем уведомлений. Конфигурация Sway не меняется, однако если несколько графических сессий одновременно разделяют один пользовательский D-Bus, они также разделяют владельца уведомлений.

Запись экрана использует gpu-screen-recorder: ЛКМ на значке — активный монитор со звуком, ПКМ — область со звуком. Проверка на настоящей системе всё ещё нужна для захвата на нескольких мониторах, работы блокировки/PAM и новых элементов. Для LaTeX в AI нужен MicroTeX, он пока не упакован. Автообновление оболочки отключено: обновления задаются через Nix.

Сборку без переключения системы можно проверить так:

```sh
nix build --no-link .#nixosConfigurations.$(hostname).config.system.build.toplevel
```
