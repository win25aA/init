# illogical-impulse: экспериментальный перенос

**Черновик: ещё не проверен сборкой NixOS и запуском в Hyprland. Не используйте его как готовую конфигурацию и не сливайте в universal.**

Код ii и зависимости зафиксированы в `pkgs/illogical-impulse`. Hyprland запускает ii; Sway продолжает запускать Noctalia. Личные Lua-настройки Hyprland сохранены. Цвета генерирует matugen.

`config/config.json` и `config/hypr-overrides/` подключены живыми симлинками. Изменения через GUI попадают в рабочее дерево репозитория. Для отдельного ПК можно задать `my.illogicalImpulseConfigDir`; там должны находиться `config.json` и каталог `hypr-overrides` с `main.lua`. GUI-настройки не стоит без просмотра автоматически коммитить: в них могут оказаться личные данные или ключи API.

Черновые вкладки радио и Wallhaven находятся в левой панели. Запись использует gpu-screen-recorder; ЛКМ на значке — активный монитор со звуком, ПКМ — выбор области со звуком. Смена обоев и цветов, радио, Wallhaven, выбор области на нескольких мониторах, блокировка/PAM и все элементы GUI требуют проверки на настоящей системе. Для LaTeX в AI нужен MicroTeX, он пока не упакован. В радио используется mpv с MPRIS; смена громкости из настроек действует при следующем запуске станции.

Перед любым применением необходимо отдельно проверить сборку без переключения системы:

```sh
nix build --no-link .#nixosConfigurations.$(hostname).config.system.build.toplevel
```

До успешной сборки и проверки блокировки не использовать эту ветку как основную. В тестовом окружении Nix и Hyprland недоступны; проверены только применимость патча, синтаксис shell/Python/JSON и параметры записи на заглушках.
