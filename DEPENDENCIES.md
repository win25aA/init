# Файлы, оставляемые из существующего /etc/nixos

Ветка вносит изменения в существующий репозиторий, а не заменяет весь /etc/nixos.

Обязательно сохрани:
- `hardware-configuration.nix` — твоя реальная конфигурация оборудования. Не генерировалась и не подменялась.
- `simple-sddm-2/` — твоя тема SDDM, на неё ссылается configuration.nix.
- `grub-theme/` — твоя тема GRUB.
- `wallpapers/` — твоя папка обоев (и `.face`, если нужен аватар/логотип fastfetch).
- Другие локальные файлы, не затронутые PR.

Эти каталоги не были приложены к первоначальному запросу, но уже есть в Git и
сохраняются без изменений этим PR. Если `.face` отсутствует,
fastfetch использует встроенный логотип NixOS. Остальные аппаратные параметры,
диски, NVIDIA legacy_580, службы и приложения перенесены из твоего файла.

Исходные файлы сохранены в истории Git; архивный дубликат `originals/` не добавлялся.
`tests/` — автоматические тесты скрипта, а не конфигурация для установки.
