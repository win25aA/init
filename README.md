# Твой десктоп: bspwm + Home Manager + Matugen

Перенос из присланных Hyprland/Noctalia-конфигов на NixOS/X11.
SwayFX + Noctalia сохранены как запасная Wayland-сессия.
Это функциональная замена Noctalia набором X11-компонентов, не запуск Noctalia внутри bspwm
и не точная копия интерфейса и поведения Noctalia.

## Что входит

| Исходная функция | В bspwm |
|---|---|
| Окна, столы, правила, бинды | bspwm + sxhkd |
| Панель | Polybar на обоих мониторах: столы/часы слева, медиа по центру, звук/уведомления/управление/сеанс справа |
| Цвета от обоев | Твои шаблоны Matugen, `scheme-content`, dark, dominant color index 0 |
| Меню обоев | Rofi с миниатюрами без подписей, рекурсивно из `/etc/nixos/wallpapers` |
| Фон и восстановление | feh; последнее изображение сохраняется между сеансами |
| Launcher / список окон | Rofi drun / window |
| Всплывающие уведомления | Dunst: иконки, текст, действия, уровни важности, DND |
| Центр уведомлений | Отдельная сохраняемая история SQLite: последние 500 уведомлений, изображения, счётчик непрочитанных |
| История буфера | CopyQ, до 200 элементов, включая изображения; цветовая тема Matugen |
| OSD | Громкость, микрофон, раскладка, аппаратная яркость; изменения отслеживаются не только с горячих клавиш |
| Снимки и редактор | Flameshot: область, весь экран, монитор; сохранение и копирование; кнопка загрузки убрана |
| Запись экрана | Твой `gpu-screen-recorder-gtk`, доступен через меню управления |
| Ночной режим | Redshift: 4500K круглосуточно по умолчанию, переключатель с сохранением состояния |
| Управление | Rofi-меню: звук, сеть, Bluetooth, уведомления, буфер, обои, ночной режим, яркость, медиа, запись экрана |
| Сеанс | Блокировка, выход, сон, перезагрузка, выключение; опасные действия с подтверждением |
| Блокировка / бездействие | i3lock + xss-lock, блокировка перед сном и при простое |
| Погода на рабочем столе | Conky, Высокая Гора, Open-Meteo, без фона/тени |
| Скругления/размытие/тени | Picom 13, радиус окна 18, меню 20; отдельные пропускающие клики маски углов экрана, радиус 30 |
| Трей | NetworkManager, Bluetooth и другие XEmbed-приложения на основном мониторе |

Аудиовизуализатор и CPU/RAM-индикаторы не включены: в присланном `settings.toml`
они отключены. Не добавлены Wallhaven и интеграция Prism; эти плагины отключены
также в сохранённых настройках Noctalia. Само приложение prismlauncher из системного
списка пакетов не удалено: отключена интеграция оболочки, не твоя программа.

## Установка — сначала резервная копия

**Эта ветка — polished-версия X11-аналога, не законченный перенос Noctalia 1:1.**
Аппаратный конфиг, обои и темы сохранены из исходного репозитория. Этот PR не
меняет их, но перед переключением всё равно сделай резервную копию.

1. Сделай резервную копию действующего репозитория:

```bash
sudo cp -a /etc/nixos "/etc/nixos.backup-$(date +%Y%m%d-%H%M%S)"
```

2. Проверь `git status`: сначала сохрани свои незакоммиченные изменения.
   Не используй `reset --hard` или принудительное переключение для установки.
3. После просмотра PR получи ветку и переключись на неё в своём репозитории:

```bash
cd /etc/nixos
git fetch origin
git switch --track origin/bspwm-complete-polished
```

   Исходные файлы доступны в истории Git до этого PR. Архивный `originals/`
   в репозиторий повторно не добавляется. `hardware-configuration.nix`,
   `wallpapers/`, `simple-sddm-2/` и `grub-theme/` не заменяются.
4. Проверь наличие зависимостей и оценку конфигурации:

```bash
cd /etc/nixos
bash ./preflight.sh
```

5. Сначала собери, не переключая текущую систему:

```bash
sudo nixos-rebuild build --flake "path:$(realpath /etc/nixos)#winarowk"
```

6. Если сборка успешна:

```bash
sudo nixos-rebuild switch --flake "path:$(realpath /etc/nixos)#winarowk"
```

7. Выйди из текущей сессии и выбери **bspwm** в SDDM. Надёжнее первый раз перезагрузиться.
   Системное имя сессии — `none+bspwm`. Sway остаётся в списке.

`path:` использован намеренно: новые файлы попадут во flake даже до `git add`.
Для обычного git-flake новые модули сначала нужно добавить в индекс.
Твой fish-хелпер `nrs` сохранён без изменений; он делает git commit/push после сборки.
Для первого переноса используй явные команды выше, чтобы избежать автоматического push.
Не запускай `nix flake update` для установки: используй существующий `flake.lock`.

## Управление

`Super` — клавиша Win.

| Клавиши | Действие |
|---|---|
| Super + 1…9, 0 | Столы 1…10 |
| Super + Ctrl + 1…9, 0 | Перенести окно и перейти на стол |
| Super + стрелки | Фокус по направлению |
| Super + колесо | Соседний стол на текущем мониторе |
| Super + левая/правая кнопка мыши | Переместить/изменить размер окна |
| Super + F / Q / V | Полный экран / закрыть / плавающий режим |
| Super + Space | Приложения |
| Super + Tab | Список окон |
| Super + Shift + W | Миниатюры обоев |
| Super + Z | Меню управления |
| Super + P | Меню сеанса |
| Super + M | Выход с подтверждением |
| Super + L | Блокировка |
| Super + N | Сохраняемая история уведомлений |
| Super + Shift + N | Не беспокоить |
| Super + Shift + V | История буфера |
| Super + Shift + S | Снимок всего виртуального экрана в файл и буфер |
| Super + Ctrl + S / Print | Область с редактором Flameshot |
| Super + Print | Снимок монитора через Flameshot |
| Super + A / E / W / T / S | Kitty / Thunar / Firefox / AyuGram / Steam |
| Super + D / C | Показать/скрыть Vesktop / Spotify |
| Super + Shift + R | Перезапустить bspwm |
| Super + боковые кнопки мыши | Предыдущий/следующий трек |
| Мультимедийные клавиши | Громкость, микрофон, воспроизведение, треки, яркость |

На панели: клик по столу переключает его; медиа — пауза/воспроизведение,
правый клик — медиаменю, колесо — смена трека. Колокольчик открывает историю,
правый клик переключает DND. Значок управления открывает меню,
правый клик — CopyQ. Значок питания — меню сеанса, правый клик — блокировка.

## Обои и Matugen

- Источник: `/etc/nixos/wallpapers`, как в исходной Noctalia.
- Сетка с превью: 3 колонки × 2 ряда; следующие картинки доступны прокруткой.
- Папка рекурсивная; `.face` не показывается, поскольку это не обычное расширение обоев.
- При выборе запускается `matugen image … --mode dark --type scheme-content --source-color-index 0`,
  затем feh и обновление компонентов оболочки.
- Если Matugen/feh вернёт ошибку или превысит таймаут, файлы тем восстанавливаются.
- Обои в `/etc/nixos` не перезаписываются. Палитра и миниатюры создаются в твоём HOME.
- JSON-палитра Matugen: `~/.config/bspwm/colors.json`.
- Цвета оболочки: Polybar, Rofi, Dunst, CopyQ, Flameshot, Picom, Conky.
- Сохранены шаблоны Kitty, Fish, btop, GTK3/4 и mpv; удалён второй include Kitty,
  который мог перекрывать Matugen.
- Kitty получает живое обновление через сокет только текущего пользователя.
  Fish использует universal-переменные. Некоторым уже открытым GTK/Qt-приложениям,
  mpv/btop может понадобиться переоткрытие или повторный выбор темы.
- Flameshot намеренно не перезапускается при смене обоев, чтобы не потерять открытый редактор.
- Если обоев нет, создаётся резервная палитра; это не заменяет твою папку изображений.

Пути, координаты погоды и температуру меняй в начале `modules/bspwm.nix`.
Настройки Matugen — `modules/matugen.nix`, макет панели — `modules/desktop/polybar.ini`.

## Мониторы и NVIDIA

Основной: 1440×900, 74.98 Hz, позиция 0×0, столы 1–5.
Второй: 1024×768, 70.07 Hz, позиция 1440×355, столы 6–10.
При одном мониторе на него назначаются все десять столов.

В Xorg выходы NVIDIA могут называться DVI-D-0/HDMI-0, а не DVI-D-1/HDMI-A-1.
Добавлено автоопределение. Если выбрался не тот выход, выполни:

```bash
xrandr --query
```

и укажи реальные имена в `mainOutput` / `secondOutput` в `modules/bspwm.nix`.
Сначала используются твои частоты; при отсутствии режима — известная Xorg частота/auto.
Непроверенные modeline не создаются. NVIDIA legacy_580 и режим драйвера сохранены.
При отключении/подключении монитора во время работы повторно войди в сессию;
автоматическая перераскладка столов при hotplug не реализована.

## Нюансы Wayland → X11

- Noctalia — оболочка для Wayland, поэтому её IPC/слои не перенесены напрямую.
  Меню управления и уведомлений заменены Rofi/Dunst/CopyQ, а не копией QML-панелей.
- Нет Wayland layer-shell и идентичного эффекта Hyprland blur. Picom даёт близкие
  скругления/тени/размытие; прозрачность зависит от самого приложения.
- В bspwm другой алгоритм тайлинга; `window_gap=10` не является точной копией пары
  Hyprland `gaps_in=5`, `gaps_out=10`.
- Special workspace заменён скрываемым плавающим окном. Vesktop/Spotify запускаются
  при первом вызове, затем показываются/скрываются; это не отдельный workspace Hyprland.
- Alt+Shift меняет us/ru; keysyms sxhkd могут зависеть от раскладки. Если буквенный
  бинд не работает на ru, проверь `xev` и настрой бинды/коды под реальную клавиатуру.
- Переменные Wayland/NVIDIA не задаются глобально для X11. Профиль bspwm не
  исполняется для Sway; Wayland-переменные возвращены в его собственный запуск.
- sxhkd запускается Home Manager только из X11-сценария; собственные сервисы
  оболочки привязаны к `bspwm-session.target`. Noctalia не запускается в bspwm.
- Портал GTK подходит для файловых диалогов. Wayland ScreenCast/wlr не работает
  в bspwm; демонстрация экрана в X11-приложениях использует их X11-захват.
  Electron/браузеру может понадобиться перезапуск после перехода из Wayland.
- GTK/Qt-темизация не абсолютно одинакова. Оставлены твои adw-gtk3/Papirus/gtk3-platformtheme.
- X11 не изолирует клиентов так, как Wayland. CopyQ хранит историю на диске;
  не копируй секреты в постоянную историю, используй настройки исключений CopyQ.
- Аппаратная яркость через brightnessctl работает только при наличии backlight-устройства.
  Для внешних DVI/HDMI-мониторов может понадобиться DDC/CI; Redshift — это
  цветовая температура, не регулировка физической подсветки.
- Экран блокируется i3lock/PAM. Отключённые в исходных настройках виджеты
  lockscreen не воспроизводились; это обычная защищённая блокировка, не Noctalia-login-box.

## Уведомления, DND и приватность

Dunst показывает всплывающие карточки; действия работают, пока уведомление живо.
Отдельный D-Bus-monitor сохраняет последние 500 карточек в SQLite и не даёт
потерять историю при перезапуске Dunst. OSD в историю не попадает.

`~/.local/state/bspwm/notifications.sqlite3` и `notification-images/` приватны
по Unix-правам, но **не зашифрованы**. Историю можно очистить в меню уведомлений.
Действия приложения из старой архивной карточки не восстанавливаются: сохраняются
текст/иконка/изображение, а не действующие D-Bus callback-идентификаторы.

На время блокировки закрываются карточки, приостанавливаются Dunst, OSD и сбор
буфера CopyQ; после разблокировки возвращается прежнее состояние DND/CopyQ.
Архив может продолжать получать уведомления в фоне. Если нужна полная остановка
записи чувствительных уведомлений, останови `bspwm-notification-archive.service`.

## Диагностика и откат

```bash
bspwm-desktop status
systemctl --user --failed
journalctl --user -b -u bspwm-polybar -u bspwm-notifications
journalctl --user -b -u bspwm-notification-archive -u bspwm-copyq
journalctl --user -b -u bspwm-picom -u bspwm-nightlight
journalctl --user -b -t sxhkd
```

Имена/кнопки мыши: `xev`; раскладка: `xkb-switch`; мониторы: `xrandr --query`.
Для ручного повторного применения темы: `bspwm-desktop theme-reload`.

Если GLX даёт мерцание/чёрные окна на NVIDIA, поменяй `compositorBackend = "glx";`
на `"xrender"` в `modules/bspwm.nix` и пересобери систему. Для xrender автоматически
используется kernel blur вместо dual_kawase: простая замена backend без смены
метода размытия некорректна. Аппаратный GLX требует проверки на твоём драйвере.
Если ночной режим был отключён из меню, состояние хранится в
`~/.local/state/bspwm/nightlight-disabled`; включи через меню снова.

Откат: выбери предыдущее поколение NixOS в GRUB или выполни
`sudo nixos-rebuild switch --rollback`, затем восстанови конфиги из резервной копии.
Не удаляй старые поколения до успешного входа и проверки bspwm.

## Проверки

Результаты этого запуска см. в `VALIDATION.md`. Проверки в изолированной среде
не заменяют реальную сборку на твоей машине с её hardware-configuration и темами.
Зависшая проверка захвата Flameshot из старого запуска намеренно не повторялась.

```bash
python -m unittest discover -s tests -v
```

Для Python-тестов нужен Pillow. Для работы runtime также нужны dbus-next и
python-xlib; Home Manager упаковывает их автоматически.

## Обновлённое оформление и анимации

- Панель — одно настоящее скруглённое окно, без Powerline-торцов из символов
  и кусочков фона за отдельными надписями. Отступ от экрана 16 px, сверху 12 px.
- Меню — радиус 20 px, внутренние элементы 12 px, единые интервалы и тонкий
  акцент выделения вместо сплошной яркой заливки.
- Обои — настоящие фотографии с антиалиасными прозрачными углами; превью
  квадратные, с центральным кадрированием. Рамка точно охватывает изображение.
  Число рядов адаптируется к количеству файлов, без пустого второго ряда.
  На экране высотой до 800 px карточки уменьшаются, чтобы два ряда не перекрывали панель.
- Picom 13: появление окон/меню — мягкое увеличение 0.97 → 1 и fade за 220 мс;
  закрытие — scale/fade за 150 мс. У уведомлений отдельные 200/140 мс.
  Перерисовка полная (`use-damage = false`), чтобы не оставлять следов эффектов.
- Анимация растягивания при изменении геометрии намеренно выключена:
  экспериментальный эффект не нужен ценой артефактов при тайлинге.
- Для уменьшения движения выставь `reduceMotion = true;` в `modules/bspwm.nix`
  и пересобери систему. Скругления останутся, анимации отключатся.
- Отдельно выданные снимки и видео polished-архива сделаны в настоящем X11.
  Их демонстрационный фон и кадрирования не заменяют `/etc/nixos/wallpapers`.
  Медиафайлы и локальные логи проверки в Git повторно не добавляются.

Это визуально согласованный X11-аналог, не точная копия анимаций Noctalia.

Демонстрационный фон доступен только в ранее выданном polished-архиве.
В этой ветке каталог пользовательских обоев и путь по умолчанию не менялись.
