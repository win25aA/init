# NixOS: Sway / Hyprland / bspwm

bspwm добавлен рядом с существующими Wayland-сессиями. Python-обвязки нет:
настройки — в Home Manager, небольшие исполняемые команды создаются из Nix.

## Структура

- `configuration.nix` — системные настройки, регистрация `bspwm-hm` в SDDM, PAM.
- `home.nix` — импорты пользовательских модулей.
- `modules/bspwm.nix` — окна, мониторы, автозапуск через отдельный systemd target.
- `modules/polybar.nix` — запуск оригинальных Varinka / Silvia, переключение и действия.
- `modules/polybar/` — рабочие INI, лицензия и ссылка на оригинал, без дубликатов.
- `modules/sxhkd.nix` — бинды из Sway и управление звуком.
- `modules/picom.nix` — скругления 10px, тени и размытие GLX.
- `modules/rofi.nix`, `dunst.nix` — меню, уведомления и история.
- `modules/wallpapers.nix` — выбор обоев, обязательный Matugen, feh на обоих экранах.
- `modules/screenshots.nix`, `lockscreen.nix`, `clipboard.nix` — соответствующие функции.
- `modules/matugen.nix` — ВСЕ шаблоны цветов, их выходные пути и хук обновления.

## Первый запуск

После получения этой ветки в своём локальном репозитории:

```sh
sudo nixos-rebuild build --flake /etc/nixos#winarowk
sudo nixos-rebuild boot --flake /etc/nixos#winarowk
```

Сохрани работу и перезагрузись, затем выбери `bspwm-hm` в SDDM.
`boot` не перезапускает текущую графическую сессию. Flake.lock обновлять не нужно.
Если `/etc/nixos` не твоя рабочая копия, используй фактический путь к ней.
Сначала сохрани свои локальные изменения; не делай принудительный reset/checkout.

Мониторы: 1440×900 ~75Гц в 0×0 (столы 1–5), 1024×768 ~70Гц в 1440×355
(столы 6–10). В `modules/bspwm.nix` можно задать точные имена из `xrandr --query`.
Пока они пустые, используется поиск по режиму; пользовательские modeline не создаются.
При одном мониторе все 10 столов располагаются на нём.

## Управление

- Super+Space — приложения; Super+Shift+W — обои.
- Super+P — сессия; Super+Z — управление; Super+N — уведомления.
- Super+L — блокировка; Super+Shift+V — история текстового буфера.
- Super+Shift+S / Super+Ctrl+S — весь рабочий стол / область, PNG в `~/Pictures`.
  При выборе области подтверди результат в редакторе Flameshot.
- Остальные бинды приложений, столов и управления окнами сохранены из Sway.

Обои берутся из `/etc/nixos/wallpapers`. `set-wallpaper FILE` сначала выполняет
Matugen с `scheme-content --source-color-index 0`, затем feh. При ошибке Matugen
обои не меняются; частично записанные старые шаблоны сам Matugen не откатывает.
`choose-wallpaper` открывает Rofi с превью. Обои одинаковые на всех мониторах.

Цвета хранятся в `~/.local/state/bspwm/`. В `matugen.nix` есть начальная палитра
до первой генерации. Хук в Wayland не трогает службы bspwm.
Службы X11 стартуют только с `bspwm-session.target` и останавливаются при выходе.
Погода, Wallhaven и PrismLauncher-плагины не переносились.

## Темы Polybar

Varinka сохранена и остаётся темой по умолчанию. Silvia — вторая оригинальная
панель gh0stzk: во всю ширину, круглые индикаторы рабочих столов и подчёркивания
модулей. В Silvia нет профиля, погоды и сети; музыка и питание оставлены.
Другие виджеты из исходного rice не устанавливаются.

Переключение без пересборки:

```sh
polybar-theme             # меню Varinka / Silvia
polybar-theme silvia
polybar-theme varinka
```

Также: Super+Z → «Тема панели»; в Silvia — правый клик по значку Arch.
Выбор сохраняется в `~/.local/state/bspwm/polybar-theme` и применяется к обоим
мониторам. При переключении в Sway/Hyprland сохраняется только выбор для следующего
входа в bspwm: службы X11 не стартуют. Обои и настройки остальных приложений
переключатель не меняет. Палитры обновляются по сохранённым обоям перед
переключением; при ошибке Matugen старая тема остаётся.

У Silvia отдельный шаблон `silvia-colors.ini` внутри `modules/matugen.nix`:
фон — Material surface_container, текст — on_surface, акценты — primary /
secondary / tertiary, питание — error. После смены обоев Matugen обновляет обе
палитры; активная тема остаётся выбранной. У Varinka прежний шаблон сохранён.
Исходные INI Silvia адаптированы из закреплённой ревизии автора; ссылка и список
адаптаций — `modules/polybar/silvia/SOURCE`, общая лицензия — `modules/polybar/LICENSE`.

## Важные ограничения

- Полная исходная панель запускается на обоих мониторах, без сокращения модулей.
  На 1024px она может не поместиться. XEmbed-трей нельзя дублировать: значки будут
  только в одном баре. Батарея выводится лишь при наличии устройства.
- Значок обновлений: `?` — не проверялось/ошибка, `0` — nixpkgs совпадает с unstable,
  `↑` — ревизия отличается. Это не количество обновляемых пакетов; автоматического
  обновления системы нет. Проверка выполняется по клику.
- Буфер — только текст, временная история в XDG_RUNTIME_DIR; не копируй туда секреты,
  если не хочешь их появления в истории. История Dunst не переживает выход.
- Сначала проверь ручную блокировку и сон/пробуждение. Автоматический idle-таймаут
  не включён. Picom/NVIDIA, реальные частоты и отрисовку нужно проверить на железе.
- В твоём `kitty.nix` после Matugen подключён `current-theme.conf`: его содержимое
  может перекрывать цвета. Этот пользовательский include автоматически не удалялся.
- Не запускай параллельно графические сессии одного пользователя на разных VT:
  они делят D-Bus и состояние приложений. Обычный выход/вход в SDDM поддерживается.

Диагностика: `systemctl --user status bspwm-session.target` и
`journalctl --user -u bspwm-polybar -u bspwm-picom -u bspwm-wallpaper -b`.
В случае проблем можно войти в Sway/Hyprland или выбрать прошлую генерацию в GRUB.
