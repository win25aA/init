# illogical-impulse: только QS, свой Hyprland

Ветка: `feature/illogical-impulse-qs`. Это адаптация **Quickshell-оболочки end-4**, не установка всех dots-hyprland. До проверки на твоём компьютере не сливать в `main`.

## Что меняется

- В Hyprland вместо Noctalia запускается `ii-shell`: панель, лаунчер, центр управления, уведомления, обои и меню сессии от illogical-impulse.
- Твои мониторы, раскладки, рабочие столы, правила окон и оформление Hyprland остаются. Меняется одна команда автозапуска и действия шести клавиш оболочки, но не сами сочетания.
- Sway продолжает запускать Noctalia. Её пакет, TOML-файлы и симлинки не удалены.
- Исходники QS находятся в `~/.config/quickshell/ii` (read-only из Nix). **Личные настройки** — в обычном изменяемом `~/.config/illogical-impulse/config.json`. Пересборка их не перезаписывает.
- При первом запуске из Noctalia переносится только путь к существующим обоям. Настройки панелей Noctalia и QS несовместимы и автоматически не переводятся.
- Добавлены шрифты Inter / Material Symbols, штатный PAM-сервис `quickshell`, UPower и история буфера обмена только для Hyprland.

## Что намеренно не переносится из end-4

Установщик, его конфиги Hyprland, Fish, Kitty, GTK/Qt и Matugen не используются. Смена обоев создаёт палитру **только QS**. Текущая тема окон, включая сохранённый `noctalia.lua`, остаётся как была.

Переключатели QS, которые пытаются записывать настройки композитора через `HyprlandConfig`, не применяются: постоянные параметры окон меняй в своём `settings.lua`. AI/онлайн-галереи по умолчанию выключены, Arch/pacman-проверка обновлений отключена. Это не полный перенос всех возможностей end-4; например, MicroTeX/LaTeX в чате отдельно не упакован. Систему обновляй обычным NixOS-способом, не через установщик dots.

Сам **Quickshell берётся из твоего nixpkgs**, без пересборки его рецепта ради дополнительных Qt-модулей. QML-исходники end-4 закреплены отдельно в `flake.lock`, включая shapes-submodule. Добавление QS не обновляет существующие nixpkgs/Home Manager/SpotX. Отсутствующие в binary cache зависимости всё равно могут собираться локально — гарантии «вообще без компиляции» нет.

## Как безопасно попробовать

Сначала проверь `git status` в `/etc/nixos` и сохрани резервную копию своих настроек Noctalia. **Не делай `reset --hard`** ради переключения. Для пробы удобнее отдельная рабочая папка: она не трогает незакоммиченные файлы основного конфига.

```bash
cd /etc/nixos
git fetch origin
git worktree add "$HOME/nixos-ii-test" origin/feature/illogical-impulse-qs
sudo nixos-rebuild build --flake "$HOME/nixos-ii-test#winarowk"
```

Если папка `~/nixos-ii-test` уже существует, не удаляй её наугад — выбери другое имя. После успешной сборки можно применить **до перезагрузки, без смены загрузочного поколения по умолчанию**:

```bash
sudo nixos-rebuild test --flake "$HOME/nixos-ii-test#winarowk"
```

Затем выйди из Hyprland и войди снова. Простая пересборка уже работающую Noctalia не заменяет; не запускай одновременно две оболочки/службы уведомлений. **Не используй `nrs` для этой пробы**: он собирает `/etc/nixos`, делает коммит и push, а не работает с тестовой папкой.

После входа:

```bash
hyprctl configerrors
qs -c ii ipc show
```

Проверь оба монитора, панель, звук/микрофон, Wi-Fi/Bluetooth, уведомления и клавиши:

| Клавиши | Действие |
| --- | --- |
| `SUPER+Space` | Лаунчер |
| `SUPER+SHIFT+W` | Обои |
| `SUPER+P` | Меню сессии |
| `SUPER+Z` | Центр управления |
| `SUPER+SHIFT+S` | Снимок выбранного монитора → буфер обмена |
| `SUPER+CTRL+S` | Снимок области → буфер обмена |

Скриншоты сделаны через Hyprshot: функциональность сохраняется, интерфейс не тот же, что у Noctalia. Автоблокировка при запуске не включена. Экран блокировки QS сначала проверь вручную, имея доступ к TTY; не полагайся на него до проверки разблокировки своим паролем.

Сборка/evaluation не заменяет графическую проверку на твоём NVIDIA и двух мониторах. Эта ветка предназначена для такой проверки, а не обещание, что все дополнительные функции upstream уже работают.

## Что проверено автоматически

- Разбор всех 92 Nix-файлов и Python-хелперов.
- Вычисление полной системной конфигурации, PAM и Home Manager.
- Применение патча к закреплённым исходникам с shapes-submodule.
- Реальная сборка отдельного QS-пакета в изолированном Nix-окружении, запуск `qs --help` и генерация первой палитры.
- Создание JSON без перезаписи существующего профиля; ошибочная генерация не заменяет последнюю палитру.
- Старые узлы lock-файла не изменены, файлы не удалены.

Полный интерфейс не проверен: headless-тест останавливается на отсутствии Wayland/PanelWindow backend. Панель, IPC, блокировку и устройства надо проверить в настоящей Hyprland-сессии. Успешная сборка пакета не доказывает работу всего интерфейса.

## Если хочется вернуть Noctalia

После `nixos-rebuild test` обычная перезагрузка вернёт загрузочную конфигурацию по умолчанию. Личные данные QS останутся, Noctalia TOML не изменялись. Либо примени свой основной конфиг (сначала убедись, что `/etc/nixos` действительно на нужной ветке):

```bash
sudo nixos-rebuild switch --flake /etc/nixos#winarowk
```

После возврата выйди из сессии и войди снова. Не удаляй JSON QS или папку теста, пока не убедишься, что больше не нужны.
