# Компьютеры (hosts)

Каждая папка здесь — один компьютер. Имя папки = имя компьютера (hostname).
Общий конфиг лежит в `modules/`, а тут только то, что отличается от ПК к ПК:
видеокарта, загрузка, мониторы, лишние диски.

`flake.nix` сам находит все папки, кроме `_template`.

## Новый ПК

1. Поставить NixOS с флешки и склонировать репозиторий в `/etc/nixos`.
2. Скопировать шаблон (вместо `мой-ноут` — любое имя латиницей):

       cd /etc/nixos
       cp -r hosts/_template hosts/мой-ноут

3. Создать файл с дисками именно этого ПК:

       sudo nixos-generate-config --show-hardware-config > hosts/мой-ноут/hardware-configuration.nix

4. Открыть `hosts/мой-ноут/default.nix` и поменять 2 строки:
   - `my.gpu` — какая видеокарта;
   - `my.boot.mode` — `uefi` или `bios`.
5. Добавить новую папку в git (без этого flake её не увидит) и собрать:

       git add hosts/мой-ноут
       sudo nixos-rebuild switch --flake .#мой-ноут

Дальше всё как обычно: `nrs` сам берёт имя текущего ПК.
